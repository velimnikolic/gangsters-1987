# Ledger 1987 fonts

Type the outfit ledger is set in. Loaded at runtime from `Resources/Ledger1987`
by `LivingCity.UI.LedgerStyle`, which builds dynamic TMP font assets from them -
no baked SDF assets to keep in sync.

| File | Role in the book | Licence |
|---|---|---|
| SpecialElite-Regular.ttf | the typewriter - headings, names, typed labels | Apache 2.0 (`LICENSE-SpecialElite-Apache2.txt`) |
| CourierPrime-*.ttf | the ledger's figures and body copy | OFL 1.1 (`OFL-CourierPrime.txt`) |
| OldStandard-*.ttf | the newspaper's masthead and text | OFL 1.1 (`OFL-OldStandardTT.txt`) |
| BarlowCondensed-Bold.ttf | tabloid headlines, rubber stamps, label-maker tape | OFL 1.1 (copied from Assets/Synty/InterfaceModernMenus/Fonts) |
